# FasterGameplayV2

A conservative client-side settings tuner for Minecraft Java 26.2 / NeoForge / Java 25. It does not intentionally alter the F3 debug screen. It attempts to lower render distance, simulation distance, entity distance, mipmaps, biome blend, clouds, particles, and graphics mode where the relevant options are available.

FPS gains depend on hardware and settings. This client-side mod cannot guarantee a 20-30 FPS increase or reduce network ping.

Build with Java 25 and Gradle: `gradle clean build`. Output: `build/libs/fastergameplayv2-1.0.0.jar`.
